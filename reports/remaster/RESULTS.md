# 한글 리마스터 검증 · 2026-10-02

원본과 같은 MaleCNS 연결망, 시드, PCG64 난수, float32 LIF 식과 1밀리초 적분을 유지했습니다.
발화한 뉴런만 연결을 전달하는 JIT 경로와 감각 입력의 반복 할당 제거를 적용했습니다.
수신과 실제 몸체 반영을 같은 물리 프레임에서 처리하고 실행별 통신 포트를 분리했습니다.

## 검증 결과

- 원본 회귀 검증과 신규 검증 **34개 모두 통과**, 건너뛴 검사 없음.
- 실제 전체 연결망 **1,000회 적분**: 막전위, 시냅스, 스파이크, 불응기,
  발화율, 기저 전류, PCG64 상태가 매 적분 후 **정확히 일치**.
- 원본·고속 앱 **150개 몸체 프레임**, 환경시간 3초 대조:
  운동 출력, 관측 회로의 발화율, 실제 몸체 이동 궤적이 일치.
- 인위적 DNp09 자극으로 **4.033731단위 실제 이동**. 좌·우 운동 뉴런 자극으로
  올바른 방향 회전 확인. 정지, 20밀리초 한 프레임 진행, 초기화, 정상 종료 및
  소유 프로세스 정리 확인. 초기화 후 무자극 기본 상태의 운동 출력은 0.
- 앱 콘솔 오류 없음. 완료된 뇌 프레임 → 원본 디코더 → 실제 몸체 위치 응답 →
  다음 감각 입력의 인과 순서와 시간 연속성 확인.

Python 신경 상태 비교는 비트 단위 일치입니다. Godot 로그와 Python 패킷을 대조할 때는
Godot JSON의 소수 표현 반올림만 허용하는 절대 오차 1e-12를 사용했습니다.

## 성능

Ryzen 3 4100 / Radeon RX 570 / Windows / Godot 4.6.1, 전체 화면 3840×2160.
측정은 실제 전체 앱의 완료된 프레임만 포함합니다. 같은 20밀리초 뇌 프레임에서
고속·원본을 순차 실행했으며, 검사 중 정지·한 프레임 진행도 포함했습니다.

| 지표 | 원본 계산 | 고속 계산 |
|---|---:|---:|
| 뇌 20밀리초 계산 중앙값 | 200.97밀리초 | 52.07밀리초 |
| 뇌 계산 95백분위 | 226.80밀리초 | 56.35밀리초 |
| 계산·전송·몸체 응답 중앙값 | 216.94밀리초 | 66.63밀리초 |
| 몸체 응답 대기 중앙값 | 11.91밀리초 | 7.01밀리초 |
| 관측 환경시간/처리 실제시간 | 0.088배 | 0.280배 |
| 화면 렌더링 중앙값 | 60프레임/초 | 60프레임/초 |

같은 앱 구성에서 계산 중앙값 **약 3.86배**, 전체 프레임 중앙값 **약 3.26배** 개선.
별도 전체 상태 대조 실행에서는 1밀리초 적분 중앙값 12.98 → 2.77밀리초로 약 4.69배 개선했습니다.
초기 로딩·안정화, 사용자 정지시간은 위 처리율과 별개입니다. 지속적인 실시간 성능을
인증하는 장시간 부하 검사는 아닙니다.

**뇌시간과 실제시간의 1:1 목표는 미달입니다.** 고속 실행 150개 프레임 모두
20밀리초 예산을 초과했습니다. 화면은 목표 미달과 실제 처리율을 표시합니다.
프레임 수를 맞추기 위해 신경 적분을 생략하거나 난수·가중치·디코더를 바꾸지 않았습니다.

## 움직임의 해석

기본 시작 실험은 **인위적인 운동 뉴런 경로 검사**입니다. 환경시간 0.5–2.5초 동안
DNp09에 전류 3.0을 넣고 실제 LIF 결과로 움직입니다. 수동 검사도 실제 운동 뉴런에
전류를 넣으며 몸체 직접 조종이나 행동 스크립트가 아닙니다. 화면과 사건 로그에
인위적 자극의 시작·종료를 표시합니다.

자연 감각만으로 자발적 보행, 섭식, 구애, 회피가 재현되었다고 주장하지 않습니다.
무자극·감각 실험에서 운동 뉴런 출력이 0이면 몸체가 정지하는 원본 의미를 유지했습니다.
현재 개선은 계산·관찰·검사·실행 품질에 대한 리마스터이며, 자연 행동의 해결과 구분합니다.
