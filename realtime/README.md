## Exact discrete semantics

1. Clear `incoming` at start. The previous timestep threshold buffer is still present.
2. Brian2 `connections.pre` consumes that buffer at `before_groups`, order -1, with
   zero Brian delay. This delivers spikes ONE timestep after firing, as in `Brain.step`.
3. Sum signed `w` into `incoming`, then `syn *= decay; syn += gain * incoming`.
   This preserves gain AFTER sum, rather than multiplying each individual synapse first.
4. Capture eligibility before decrementing integer refractory state; eligible neurons
   take the same Euler membrane step, others remain held at reset.
5. Threshold then reset sets refractory to 2. The next TWO complete timesteps cannot fire.
6. Activity decays once and jumps on reset (same spike-derived EMA). StateMonitor is END slot.

Dimensionless equations preserve the actual reference's dimensionless LIF interpretation.
No physiological voltage fitting is implied. Float32 reduction order can differ. Noise is
explicitly OFF only; Gaussian noise equivalence belongs to a future Gate B, not this probe.
The baseline heterogeneity vector is generated by the ORIGINAL NumPy2.4 reference and exported
as float32, so switching the candidate's NumPy does not regenerate or change seeded drive.
LC4/LPLC2 external amplitude 3 is the unchanged existing sanity input. DNp09 is observation-only.

## Measurements and limits

Smoke: 0.5s warmup + 0.5s baseline + 0.5s stimulus + 0.5s recovery.
Benchmark: candidate 0.5s warmup + contiguous 10s baseline + contiguous 10s stimulus.
Reference benchmark: same initial state/drive, 0.5s warmup + contiguous 10s baseline.
Spike count and selected activity monitor costs INCLUDED; initial array loading/build/output excluded
from Network.run throughput but reported separately. Reference includes scalar population readout.

std::chrono C++ wall timers bracket actual Network.run, independently of Brian's std::clock timer.
RSS sampler includes compiler/executable children and distinguishes candidate binary from Python prep.
Full C++ i/j/w arrays are verified exactly against verified runtime CSR AFTER actual execution.
Existing integration compute-vs-remainder is taken from its already delivered same-run exit timers,
without new ecological validation or any IPC changes. This is aggregate wall overhead, including
startup/waits; it does not predict steady-state Brian2+Godot throughput.

Only one deterministic seed, LC4/LPLC2→GF plus secondary DNp09, and simple firing loads were tested.
No noisy equivalence, other circuit suite, compound burst, live standalone stepping protocol,
or ecological migration was implemented. Stop at candidate classification.
