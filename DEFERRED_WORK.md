# Deliberately deferred — v0.2 / research

MVP completion does not mean biology is complete. No item below is implemented
by the freeze, and none is a hidden v0.1 implementation promise.

| Card | Why deferred | Reopen only when | Scientific / engineering risk |
|---|---|---|---|
| Custom event-driven C++ consumer | Beyond cheap Gate E changes | New measured consumer design can pass exact-input comparison | Delivery order, float32 accumulation, refractory timing |
| Custom C++ or Rust SNN backend | New backend exceeds MVP | Funded separate validation project | Duplicated implementation and long-term maintenance |
| GeNN / CUDA / GPU | No production GPU equivalence work | Suitable hardware and explicit migration study | Reduction order, RNG streams, transfer overhead |
| Higher-end CPU | Existing target characterized | New hardware is actually available | Benchmark comparability; no guaranteed proportional gain |
| Alternative Gaussian supply / producer pipeline | Producer alone solved, consumer contention remains | A consumer first demonstrates stable headroom | Stream assignment, contention, hidden copy/wait costs |
| dt=2 ms | Scientific semantics change | Explicit numerical-model experiment | Spike timing and integration stability |
| Deeper synaptic delivery rewrite | Major consumer design work | New concrete profiling-backed algorithm | Sign, delay, causality, summation order |
| Model simplification / different integration | Weakens identity if silently adopted | Explicit separate scientific question | Changed biological interpretation; invalid old certificates |
| Directional retinotopy / locomotor decoder | Existing mapping supports only pooled features and experimental scalar decoding | Actual receptive-field/body mechanics evidence | Scripted steering masquerading as neural behavior |
| Feeding / courtship / neural pain | Functional paths remain unresolved | Annotation plus controlled circuit and behavior evidence | Enabling behavior from unvalidated labels |
| Neural defecation / metabolism | Current world physiology is explicitly placeholder | Adult circuit evidence and a distinct research scope | Borrowing incompatible larval or peripheral semantics |

Keep historical evidence. Future work is bug fixes, new experiments, an explicit
performance revisit, or v0.2. Do not add species, multi-fly breeding, cloud, LLM
steering or a full-neuron visualization to this frozen MVP.
